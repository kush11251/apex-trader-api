# Apex Trader API
A high-frequency trading platform with real-time market data and algorithmic trading capabilities.

## Installation
1. Clone the repository: `git clone https://github.com/user/apex-trader-api.git`
2. Initialize the Go module: `go mod init apex-trader-api`
3. Install dependencies: `go get -u github.com/gorilla/mux`
4. Run the application: `go run src/main.go`
